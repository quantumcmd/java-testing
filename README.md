# Prácticas de Testing con JUnit

## Descripción
Este repositorio contiene el código y los commits correspondientes a las prácticas de los 13 vídeos de la serie sobre JUnit. Los commits reflejan el progreso continuo a lo largo del curso.

## Notas de Configuración: JUnit 4 vs JUnit 5
Durante las explicaciones de los vídeos se utiliza **JUnit 4**. Sin embargo, este proyecto ha sido configurado y desarrollado utilizando **JUnit 5 (Jupiter)** desde el inicio para aplicar los estándares más modernos de la industria.

Para mantener la consistencia en el historial de Git, todo el código de las prácticas ha sido adaptado a JUnit 5. Esto significa que las anotaciones de ciclo de vida, el manejo de excepciones y la estructura de las aserciones han sido actualizados a sus equivalentes modernos en Jupiter.

Esta adaptación se ha realizado de manera consciente como parte del proceso de aprendizaje. Me ha servido para interiorizar la lógica detrás de los tests y demostrar que he comprendido y trabajado activamente con el material, aplicándolo directamente a las herramientas actuales de Java.
